# D1 Lab

Liquid AIの **d1-3B / d1-omni-600M** を、iPhoneやApple Silicon Macで試すアプリです。文章・写真・録音から答えを選び、候補の確率と処理速度を確認できます。iOSではMetalを使って端末内で推論します。

[English](README.en.md) · [はじめて使う](apps/d1_lab/docs/quickstart.md) · [ビルド手順](apps/d1_lab/docs/building.md) · [プライバシー](apps/d1_lab/docs/privacy.md)

アプリの準備は [ビルド手順](apps/d1_lab/docs/building.md) を参照してください。起動後は、以下のサンプルから試せます。

## 最初に試す

1. 起動して「タスクを選ぶ」の日本語サンプルから「口コミの印象」を選びます。
2. モデルを **d1-3B** にします。
3. 「モデルを取得して始める」→「このタスクに必要なモデルを取得」でダウンロードします。
4. 「試す」に戻り、「判定を実行する」を押します。
5. 結果で「好意的・否定的・中立」の答えと確率を確認します。
6. 文章を「料理が冷たく、長く待たされた」などに変え、もう一度実行して比較します。

入力は「判断の材料」「何を判断するかという指示」「答えの候補・評価段階」の組み合わせです。サンプルを選ぶと、すべて入力されます。判定条件を開くと指示や候補を変更できます。

## 写真と録音を試す

**写真:** 「タスクを選ぶ」→「画像」→「写真の主な色」を選びます。「カメラで撮る」または「写真から選ぶ」で1枚を添付し、必要なモデルを取得して実行します。「写っている物を分類」「書類の種類を判定」「カップが写っている？」も試せます。

**録音:** 「タスクを選ぶ」→「音声」→「声で操作を選ぶ」を選びます。d1-omniが選択されます。「マイクで録音」で話し、「停止して使う」→「判定を実行する」の順に進みます。録音は最大30秒です。

写真・録音のタスクは「補足」を空のまま実行できます。判定指示と選択肢はタスクに設定しておき、録音内容を文字で入力する必要はありません。omniの音声機能は英語の発話で学習されています。日本語の音声は実際に試して精度を確認してください。自由な会話や文字起こしを返すモデルではありません。

画像・音声のタスクにはモデル本体に加えて追加データが必要です。「このタスクに必要なモデルを取得」でまとめて取得できます。画像と音声は、1回につきどちらか1件を使います。初回のカメラ・マイク操作ではOSの使用許可が必要です。

Macでは「写真から選ぶ」または「ファイルから取り込む」で画像を添付します。カメラ撮影はiPhoneで試してください。

写真カードの「画像の長辺」で256・512・768・1024・1536・2048pxを選べます（初期値2048px）。縦横比と向きを保ち、小さい画像は拡大しません。表示された縦横サイズが判定に渡す画像のサイズです。添付後に変更すると元画像から作り直すので、縮小を繰り返して画質が落ちることを防げます。元画像も端末に保存するため、その分の空き容量を使用します。過去の履歴の画像は変更しません。設定ごとのTotal・画像処理時間・入力トークン数を比べて試してください。画像の準備やサイズ変更の時間は、判定のTotalに含みません。

## 結果の読み方

| 表示 | 意味 |
| --- | --- |
| Choice | 指定した候補の確率と、選ばれた答え |
| Noul | 「はい」の確率。0.5付近は判断が不確か |
| Score | 低い順に0・1・2…とした評価段階の期待値 |
| Total | 今回のファイル確認・必要な読み込みと解放・判定・受け渡しの合計時間 |
| Prefill tok/s（3B） | 処理した入力トークン数を、主モデルの計算時間で割った速度 |
| Input speed（omni） | 双方向エンコーダーと判定ヘッドによる入力処理速度 |

「計測の内訳」で読み込み、画像・音声処理、モデル計算などの時間を確認できます。tok/sには読み込みと画像・音声のエンコード時間を含めません。Totalには撮影・録音の操作時間、履歴の保存、画面描画を含めません。結果には「モデル読み込みあり」または「読み込み済みを再利用」を表示します。

画面上部の「モデルを準備」で、入力前に選択中のモデルをロードできます。画像・音声タスクでは追加データも準備します。準備後は「準備完了」と準備時間が表示され、最初の判定から読み込み済みモデルを使います。事前準備の時間は判定結果のTotalに含みません。「解放」でメモリから外せますが、ダウンロード済みファイルは残ります。「モデルを準備」を使うと、モデルを保持する設定がオンになります。

通常の実行ではモデルを1つ保持し、同じモデル・実行環境・入力上限・追加データで再実行すると読み込みを省きます。文章や判定条件を変えても、入力は毎回処理されます。モデルを保持する間はメモリを使用し、アプリを離れたときやOSからメモリ不足の通知があったときに解放します。「詳細設定」の「モデルを読み込んだまま待機」をオフにすると、毎回読み込み・解放します。

「比較」では同じ入力を両モデルに順番に渡し、それぞれ新しく読み込み・解放します。OSやMetalのキャッシュ状態は揃えないため、厳密な初回起動速度の比較ではありません。モデルごとの答え・確率・速度を確認できます。音声入力はomniのみ対応しています。

## モデルと保存

モデルはアプリに同梱しません。Hugging Faceからアプリ内でダウンロードし、端末に保存します。ダウンロード再開とファイル検証に対応しています。

「取得済み」はモデルファイルが端末に保存された状態です。画面上部の「モデルを準備」を押し、「準備完了」になると判定に使えます。読み込みでエラーが出る場合は、アプリを最新版に更新してから再度準備してください。

取得する公式配布版は固定し、容量とSHA-256を確認します。アプリ更新後も、対応する旧配布版を保存済みなら再取得せず使えます。配布版が変わった場合、旧版の取得途中ファイルは新しい版に合わせて最初から取得します。

取得がHTTP 403で失敗する場合は、アプリを最新版にして再試行してください。それでも失敗する場合は時間をおいて試すか、下記の公式配布元から表と同じ量子化のGGUFを取得し、「モデル」画面の「ファイルを取り込む」を使ってください。画像・音声には対応する追加データも必要です。取り込み時も容量とSHA-256を確認します。

| モデル | 本体 | 画像・音声用の追加データ | 対応入力 |
| --- | --- | --- | --- |
| d1-3B（Q4_K_M） | 約1.67 GB | 約583 MB（Q8_0） | 文章・画像 |
| d1-omni-600M（Q8_0） | 約407 MB | 約263 MB（Q8_0） | 文章・画像・音声 |

容量は10進表記です。ダウンロードやファイル取り込みのために余裕のある空き容量を用意してください。「モデル」画面で使用容量を確認し、「モデルファイルを削除」でモデル本体・追加データ・取得途中のファイルを削除できます。必要になったら再取得できます。モデル削除で履歴や保存したタスクは消えません。

推論入力はサーバーへ送信しません。写真・録音・実行履歴は端末に保存されます。履歴を削除すると、ほかの履歴や現在の入力が使っていない素材も削除します。「モデル」→「保存データ」から、不要な素材の整理や、履歴・写真・録音の一括削除ができます。モデルと自分のタスクは残ります。元の写真や取り込む前のファイルは変更しません。詳しくは[プライバシーポリシー](apps/d1_lab/docs/privacy.md)を確認してください。

## 言語と自分のタスク

右上の翻訳アイコンから「端末の言語」「日本語」「English」を選べます。表示言語の変更は、編集中の文章や添付、過去の結果を変更しません。タスク一覧では日本語・英語のサンプルを別に選べます。

判定条件の下にある「タスク名」を入力し、「登録先」で自動選択・文章・画像・音声を選びます。初期値の自動選択では、添付した素材の種類、または選択中のタスクの種類を使います。「この条件をタスクとして保存」を押すと、「タスクを選ぶ」の該当する種類にある「自分のタスク」に追加されます。自分の入力と判定条件を再利用できます。画像・音声の保存タスクでは、呼び出すたびに写真や録音を選び直します。音声タスクではomniが選択されます。

## 対応環境

iOS 16以上、またはApple SiliconのmacOS 14以上。実機での処理速度や必要なメモリは、端末・入力・設定によって変わります。Androidの推論にはまだ対応していません。

d1-omniは実験的なモデルです。サンプルの正答を保証するものではありません。指示や候補を変え、自分の用途で判断の精度を確かめてください。
